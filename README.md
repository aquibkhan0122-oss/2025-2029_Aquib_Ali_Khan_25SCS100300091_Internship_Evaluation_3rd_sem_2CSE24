## Internship Overview

This repository contains the documents, project work, presentations, and supporting material completed during my Cybersecurity Internship at Thiranex.

The internship focused on applying cybersecurity concepts through practical projects related to password security, vulnerability assessment, phishing detection, and secure authentication.

## Projects Completed

### 1. Password Strength Analyzer

A security-focused application that analyzes password strength based on length, complexity, and uniqueness. It also provides suggestions for creating stronger passwords.

### 2. Vulnerability Scanner

A mini vulnerability assessment project designed to identify open ports, weak configurations, and potentially outdated software versions and generate a basic vulnerability report.

### 3. Phishing Email Detection Model

A machine learning project that analyzes email-related features such as URLs and keywords to classify messages as **Phishing** or **Safe**.

The project also evaluates the model using accuracy and a confusion matrix.

### 4. Secure Login System

A secure authentication system implementing user registration and login with password hashing, input validation, session management, and logout functionality. The project also considers protection against SQL injection and optional two-factor authentication.
